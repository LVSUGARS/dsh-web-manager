# 2.0 视觉转译记录

## 参考证据

- DeepSeek Harness 截图：深蓝到黑色的全幅空间、细密网格、低对比光感、白色高对比标题、蓝色强调色，以及玻璃质感的命令面板。
- Mineradio 方向：紧凑的桌面工具密度、明确的状态区域、圆角控件和少量高亮操作，不把窗口做成宣传网页。

## 转译规则

- 深色为默认视觉基线：`#07111F` 页面底色、`#122238` 半透明面板、`#78A8FF` 主强调色。
- 用细网格和斜向色阶制造空间感；不加入会抢夺操作焦点的装饰性圆球或大面积插画。
- 首页只保留一个状态主卡，主按钮随状态变为“安装 / 启动 / 打开 / 重新检测”，停止为次级动作。
- 顶栏保留鲸鱼标识、语言切换和标准窗口控制；侧栏低对比处理，避免与主状态卡争夺层级。
- 卡片圆角从 14px 提升到 16-18px，边框使用低透明度蓝灰色，按钮使用渐变只表达主操作。
- 浅色主题沿用相同结构，替换为冷白、浅蓝灰和深色文字，不重新设计一套页面。
- 开屏使用同一套深蓝网格、低对比粒子和白色鲸鱼标识；视觉只承担进入感，不添加宣传性内容或远程资源。
- 开屏的右上角沿用标准最小化、最大化/恢复、关闭顺序；`Esc` 提示放在右下角，避免与窗口控制争夺空间。

## 不照搬的部分

- 不复制 DeepSeek 官网的宣传标题、营销文案或网页滚动结构。
- 不把启动器做成终端截图展示页；命令、日志和更新信息只在需要时出现。
- 不依赖远程图片或在线字体，保证离线启动和安装包可复现。
